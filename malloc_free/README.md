# 0x0A. malloc, free

This project introduces dynamic memory allocation in C.

## Learning Objectives

- Understand automatic and dynamic memory allocation.
- Learn how to use malloc() and free().
- Understand when and why to use malloc().
- Learn how to check for memory leaks using Valgrind.

## Requirements

- Ubuntu 20.04 LTS
- GCC
- Betty style
- Code compiled with:
  `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`

# C - Pointers, Arrays and Strings

## Description

This project introduces pointers, arrays, and strings in the C programming language. It focuses on understanding memory addresses, accessing and modifying values through pointers, and working with data stored in memory.

## Learning Objectives

At the end of this project, I should be able to explain:

- What pointers are and how to use them.
- What arrays are and how to use them.
- The differences between pointers and arrays.
- How to use and manipulate strings.
- The scope of variables.

## Requirements

- Compiled on Ubuntu 20.04 LTS using GCC.
- Compilation flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Code follows the Betty coding style.
- No global variables.
- No more than five functions per file.
- No standard library functions such as `printf` or `puts` in submitted solutions.
- Function prototypes are declared in `main.h`.
